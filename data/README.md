# Pre-Nucleic Acid Origin of Life — Data

Data-only computational package for:

**Mapping Chemical Continuity Before Nucleic Acids: A Computational
Analysis of Prebiotic Molecular Chemical Space and Functional Emergence**

## Contents

- Final molecular dataset
- Independent PCA results
- PCA scores and loadings
- Chemical distance analysis
- Molecular similarity matrices
- Layer connectivity
- Bridge rankings
- Network robustness
- Cross-layer permutation validation
- Molecular layer metadata

## Directory Structure

data/
├── final_dataset/
├── chemical_space/
├── molecular_similarity/
├── layer_connectivity/
├── bridge_analysis/
├── network_robustness/
├── permutation_validation/
└── metadata/

## Dataset

The final structure-based dataset contains 188 unique molecular structures.

## Reproducibility

This directory contains the computational data outputs used for the
analysis and is provided for inspection and reproducibility.

No figures are included in this data-only package.

## Interpretation

L0–L5 are analytical chemical-function layers and should not be interpreted
as an established historical chronological sequence.

Chemical similarity and network connectivity alone do not establish
historical ancestry, abiogenesis, or a unique pathway to life.
